由**班级心理委员**维护的匿名互助小站。**留言信箱式**：消息写入 **Supabase（免费额度，境外区）**，
对方任何时间打开网页即可取信——**无需双方同时在线、免费、无服务器、无命令行**。

## 使用

把 `index.html` 发给同学，**各自打开即用，无需填任何密钥**（云端地址与公开密钥已内置）。
只有连接另一个 Supabase 项目时才需到「我的 → 云端」修改。
